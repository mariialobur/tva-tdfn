# Профессиональный аудит и доработка — TVA TDFN v15.0

## Что исправлено после аудита опубликованной v14

1. **D2 исправлен юридически:** при проверке порога 10 % обороты деятельностей с одинаковым TDFN суммируются по art. 86 al. 3 OTVA. Бухгалтерская детализация при этом сохраняется для traçabilité.
2. **Acquis ≠ Maîtrisé:** первый успешный проход после micro-théorie и exemple guidé даёт статус «Acquis». «Maîtrisé» присваивается только после повторной validation sans aide.
3. **Guided example D4** использует другие цифры, чтобы ученик применял правило, а не копировал ответ.
4. **Legal UX облегчён:** сначала видны основные нормы и одна pratique AFC, остальные ссылки раскрываются по запросу.
5. **Advanced practice:** добавлены прямые ссылки AFC на Info TVA 12 ch. 2.2.2 и 3.2.2.
6. **Calculator** больше не дублирует полный dossier; остаются компактные repères.
7. **Case I:** итоговая règle à retenir теперь формулирует переносимый навык: acquisition ≠ chiffre d’affaires ch. 200.
8. Добавлены semantic legal tests, чтобы будущие редакции текста не возвращали ошибочную логику D2.

# История предыдущей доработки — v14.0

## Почему понадобилась v14

После v13 главная проблема была уже не в количестве контента. Юридическая база стала сильной, но интерфейс всё ещё местами работал как экзамен или административная программа.

При этом целевой ученик знает TVA/TDFN **в общих чертах**. Его задача — не доказать знание темы до начала тренажёра, а постепенно превратить общую теорию в рабочие навыки.

Поэтому v14 строится вокруг принципа:

**короткая теория → пример на других данных → самостоятельное применение → разбор → норма → повтор без помощи.**

## 1. Теория теперь находится непосредственно перед практикой

Все 37 кейсов получили собственную микротеорию `À comprendre`.

Она не является конспектом главы. В ней только одна новая рабочая идея, которая нужна для текущего действия: например, база TTC, разделение нескольких TDFN, правило 10 %, qualification d’une prestation étrangère, valeur résiduelle или знак ch. 415.

Так ученик не обязан заранее помнить весь массив правил.

## 2. После правила сразу идёт Exemple guidé

Каждый кейс содержит пример на других цифрах или другой ситуации.

Пример показывает сам ход рассуждения, но не решает оцениваемый dossier пользователя. Это позволяет сначала увидеть правило в действии, а затем перенести его на новый кейс.

Примеры расчётов содержат явную арифметику там, где она помогает понять механику: HT → TTC, TDFN, несколько ставок, export, impôt sur les acquisitions, ch. 410 / ch. 415 и т. д.

## 3. Scaffolding постепенно исчезает

Во время первого прохождения микротеория и пример раскрыты.

Если кейс уже освоен или пользователь входит в режим повторения ошибок, блок теории свёрнут по умолчанию. Это важно: сначала тренажёр обучает, затем проверяет способность воспроизвести навык без опоры.

Таким образом `maîtrisé` означает больше, чем простое узнавание ответа после подсказки.

## 4. Убрана утечка ответа через интерфейс

Старый блок `Facture client / AFC` больше не показывается автоматически во всех кейсах. Он оставлен только там, где само различие между клиентской фактурой и décompte является частью навыка.

В QCM пояснение результата не выводится до ответа пользователя. Точная формулировка `Compétence consolidée` появляется после проверки, а не заранее.

## 5. Юридические источники разделены по функциям

Вместо общего блока `Base légale` интерфейс различает:

- **Fondement juridique** — LTVA / OTVA;
- **Pratique AFC** — Info TVA, актуальные страницы AFC;
- ссылки на **prototype du décompte** — когда навык связан с конкретной строкой формы.

Это учит не только запоминать правило, но и понимать иерархию источников.

## 6. Ссылки на закон стали точнее

Для ссылок LTVA/OTVA используется переход к соответствующей статье Fedlex через article anchor. Пользователь больше не должен открывать начало закона и самостоятельно искать нужную статью.

Для сложных переходов между методами добавлены ссылки на конкретные разделы практики AFC, в частности:

- Info TVA 12, ch. 2.2.2 — переход effective → TDFN;
- Info TVA 12, ch. 2.2.3 — corrections / valeurs résiduelles / ch. 415;
- Info TVA 12, ch. 3.2.2 — переход TDFN → effective;
- Info TVA 12, ch. 3.2.3 — dégrèvement / ch. 410;
- Info TVA 12, ch. 4.1 — procédure de déclaration.

## 7. Внешняя нумерация больше не показывает технические ID

Внутренние `J1`, `A`, `K5` сохранены для совместимости с сохранённым прогрессом, но пользователь видит нормальную структуру:

`1.1`, `1.2`, `1.3`, `2.1`, `2.2`…

Это делает курс последовательным и не создаёт впечатление, что обучение начинается с раздела J.

## 8. Primary CTA перенесён к месту действия

На desktop основная кнопка больше не находится в левой навигации.

Пользователь читает задачу, вводит ответ и сразу под рабочей зоной видит `Vérifier mes réponses`, `Passer au calcul` или `Transférer au décompte`.

Левая колонка отвечает только за ориентацию по курсу и вторичные ресурсы.

## 9. Основная рабочая область превращена в один canvas

Вместо стопки самостоятельных карточек используется один белый рабочий лист с последовательными секциями.

Карточки и цветовые акценты остаются только там, где они несут смысл: теория, пример, warning, feedback, особая процедура.

Рабочая ширина ограничена, чтобы длинные юридические формулировки не растягивались на весь большой монитор.

## 10. Уровни сложности нормализованы

Сложность каждого кейса теперь только:

- `Débutant`;
- `Intermédiaire`;
- `Avancé`.

Отдельно указывается тип работы: `Qualification`, `Calcul`, `Décompte`, `Transition`, `Organisation`, `Procédure`, `Atelier`.

Таким образом тема и сложность больше не смешиваются в одном label.

## 11. Повтор ошибок стал отдельным режимом

`Revoir mes erreurs` создаёт очередь кейсов, которые нужно доработать.

В режиме révision показывается позиция в очереди, а после исправления доступно `Erreur suivante →`. Пользователь не должен каждый раз возвращаться в Bilan и заново искать следующий слабый кейс.

## 12. Добавлен одноразовый onboarding

При первом входе тренажёр коротко объясняет учебную механику:

**Comprendre → Voir un exemple → Appliquer → Justifier.**

Он не дублирует курс TVA и не содержит длинной теории. Его задача — объяснить, как учиться внутри тренажёра.

## 13. Время прохождения отсутствует

В v14 нет ориентировочных минут. Ученик может задержаться на норме AFC или пройти знакомый кейс быстрее — это не должно влиять на оценку прогресса.

## 14. Технические гарантии

Перед сборкой:

- smoke: **67/67 PASS**;
- unit: **37/37 кейсов PASS**;
- JavaScript syntax: PASS;
- 37/37 кейсов имеют микротеорию;
- 37/37 имеют guided example;
- 37/37 имеют LTVA/OTVA anchor;
- 37/37 имеют отдельную практическую ссылку AFC;
- миграция v13 → v14 сохранена;
- расчёты ch. 410 / ch. 415 и таблицы переходов проходят unit-проверки.

Browser E2E включён в GitHub Actions. Локально он не объявляется пройденным, потому что в текущей рабочей среде зависимости Playwright недоступны через внутренний npm registry.

## Что сознательно не добавлялось

- длинные теоретические главы;
- таймеры;
- баллы и игровые награды;
- обязательное открытие полного dossier;
- несколько конкурирующих CTA;
- дополнительная функциональность только ради «богатого» интерфейса.

Главная цель v14 — чтобы интерфейс помогал ученику строить профессиональное рассуждение, а не заставлял сначала изучать сам интерфейс.

ОБНОВЛЕНИЕ TDFN — ФИНАЛЬНАЯ ОЦЕНКА + ATTESTATION DE PARCOURS

Что добавлено:
- отдельная финальная évaluation после 43 оцениваемых этапов;
- 12 вопросов случайно выбираются из банка 18 вопросов;
- варианты ответов перемешиваются;
- во время теста нет Aide, Solution, checklist и ссылок на источники;
- порог: 9/12 (75%);
- после сдачи показывается коррекция и официальные ссылки AFC;
- после успешной попытки открывается ATTESTATION DE PARCOURS;
- имя вводится только перед созданием attestation и не сохраняется сайтом;
- документ можно распечатать или сохранить как PDF через браузер;
- на attestation нет имени автора проекта и нет слова «certificat»;
- есть дисклеймер: не diplôme, не titre professionnel, не certification reconnue/accréditée; нет affiliation AFC/ESTV; идентичность участника не проверяется.

Как установить:
1. Скопируйте evaluation.js, evaluation.css, APPLY-EVALUATION.py и APPLY-EVALUATION.cmd в корень вашего локального проекта tva-tdfn рядом с index.html.
2. Дважды запустите APPLY-EVALUATION.cmd.
3. Скрипт создаст резервную копию index.before-evaluation.html и добавит две строки подключения в index.html.
4. Откройте сайт локально через HTTP-сервер (ES modules не следует тестировать двойным кликом file://).
5. После проверки загрузите на GitHub ТОЛЬКО:
   - index.html
   - evaluation.js
   - evaluation.css

Важно:
- Финальная оценка блокируется, пока в локальном прогрессе не присутствуют результаты всех 43 оцениваемых кейсов.
- Attestation доступна после результата минимум 9/12.
- Текущий прогресс пользователя хранится существующим тренажёром в localStorage; новый модуль не отправляет данные на сервер.

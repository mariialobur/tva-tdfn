# TVA TDFN — v16 refined

Это доработанная версия первого пакета после критического разбора. Главное отличие: улучшения теперь интегрируются прямо в ядро `index.html / app.js / styles.css`, поэтому отдельные `v16-enhancements.js/css` и `MutationObserver` больше не нужны.

## Что исправлено

- onboarding сокращён до 3 действительно необходимых идей;
- Acquis / Maîtrisé убраны с первого экрана — их смысл остаётся доступным через прогресс и появляется естественно после прохождения кейсов;
- таблица переименована в **Repères AFC pour l’entrée aux TDFN** и прямо объясняет, что суммы относятся к первой année d’assujettissement / году перед effective → TDFN, а не являются отдельными правилами maintien;
- блок реформы 2025 сокращён до сравнения **Avant / Depuis 2025**;
- юридический контекст показывается только в первом кейсе модулей 3, 7 и 8;
- контекст перенесён выше micro-théorie и задания, то есть больше не появляется после stepper;
- `MutationObserver` полностью убран: блок рендерится из `app.js` штатно;
- difficulty стал нейтральным, вторичный текст немного увеличен;
- дата проверки источников обновлена на 12.08.2026;
- 37 кейсов, расчёты, state, scoring и логика Acquis/Maîtrisé не изменяются.

## Установка

1. Распакуйте архив.
2. Самый простой вариант для Windows: распакуйте папку `tva-tdfn-v16-refined` прямо в корень репозитория `tva-tdfn` и запустите `APPLY-V16.cmd`. Скрипт сам перейдёт на уровень выше, где лежат `index.html`, `app.js`, `styles.css`.
3. Альтернатива: скопируйте `apply-v16-refined.py` в корень репозитория и выполните `python apply-v16-refined.py`.

Скрипт перед изменением создаёт резервную папку `.v15-backup-before-v16-refined/`.

После этого commit/push изменённых `index.html`, `app.js`, `styles.css` и проверьте GitHub Pages.

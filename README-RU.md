# TVA TDFN — v16.2 audited final

Финальная ревизия тренажёра после повторного экспертного аудита от 12.08.2026.

## Что исправлено после v16.1

- T1 действительно стал dossier à qualifier: названия документов больше не сообщают заранее «export», «subvention», «acquisition» или готовую рубрику.
- T2 больше не выдаёт правильные цифры в раскрываемом блоке `Contrôles et sources complémentaires`; checklist содержит только процедуру контроля.
- S4 также больше не показывает готовую числовую concordance до проверки.
- S3 переформулирован как документированное уменьшение встречного предоставления: просрочка платежа сама по себе больше не подаётся как автоматическое основание для correction.
- Для типичных ошибок T2 добавлены диагностические подсказки после проверки: `Rubrique`, `Qualification`, `Correction`, `Base`.
- В кейсе иностранного SaaS явно разъяснено: порог CHF 10’000 относится к получателю, который **не зарегистрирован** как плательщик TVA; зарегистрированный assujetti декларирует облагаемые acquisitions.
- Статический HTML приведён в соответствие с JS: `0 / 43 acquis · 0 maîtrisés` вместо старого `0 / 36`.
- Обновлены meta/OG description, subtitle и cache-busting до `16.2.0`.
- Добавлена более строгая автоматическая валидация структуры, модулей, источников, спортивных TDFN и финального dossier.

## Установка

Папку `tva-tdfn-v16.2-audited` поместите в корень репозитория рядом с `index.html` и запустите `APPLY-FINAL.cmd`.

Скрипт работает в двух ситуациях:

1. если репозиторий ещё на v15/v16 refined — сначала устанавливает базу v16.1, затем автоматически применяет аудит v16.2;
2. если v16.1 уже установлена — применяет только улучшения v16.2.

Перед вторым этапом создаётся `.backup-before-v16.2-audit/`. Исходная резервная копия `.backup-before-v16-final/` не перезаписывается.

После установки можно отдельно запустить `VALIDATE-FINAL.cmd`.

## Откат

- `RESTORE-PRE-V16.2.cmd` — вернуть состояние непосредственно до v16.2.
- `RESTORE-ORIGINAL.cmd` — вернуть исходную версию до всей финальной установки (если существует `.backup-before-v16-final/`).

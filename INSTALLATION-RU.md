# Установка версии 8.1

## Что изменяется

Версия 8.1 работает поверх существующих файлов проекта 6.3 и не требует замены `app.js`, `data.js`, `logic.js`, `styles.css`, `ui-fixes.js` и `ui-fixes.css`.

В корень GitHub-репозитория нужно загрузить:

1. `index.html` — заменить существующий;
2. `v8.1-learning-path.js` — добавить;
3. `v8.1-learning-path.css` — добавить.

Файлы старой версии `v8-learning-path.js` и `v8-learning-path.css` после успешной проверки можно удалить: новый `index.html` их не подключает.

## Перед загрузкой

1. Скачайте резервную копию репозитория или создайте отдельную ветку.
2. Убедитесь, что в корне уже находятся базовые файлы 6.3.
3. Не удаляйте пользовательские base assets до проверки новой страницы.

## После загрузки

GitHub Pages может обновляться не мгновенно. После публикации:

1. откройте сайт в приватном окне;
2. выполните жёсткое обновление страницы;
3. убедитесь, что в футере указана версия 8.1;
4. откройте прямые ссылки:
   - `#cas-K0`;
   - `#cas-K1`;
   - `#cas-K2`;
   - `#cas-K3`;
   - `#cas-K4`;
   - `#cas-K5`;
   - `#cas-L0`;
   - `#cas-L`;
   - `#cas-Q`;
   - `#cas-R`.

Старые ссылки L–Q должны открывать прежние случаи. Только `#cas-K` намеренно переводится на `#cas-K0`.

## Обязательный ручной тест

### Навигация

- выбор модуля открывает первый кейс выбранного модуля;
- список слева показывает только текущий модуль;
- стрелки переходят по педагогическому порядку;
- мобильный select содержит все случаи;
- кнопка назад браузера не приводит к неверному кейсу.

### Transition worksheets

Для K2 введите:

- `À corriger`;
- `60`;
- `486`.

После правильного заполнения основная кнопка должна проверить и таблицу, и вопросы.

Для K3:

- stock: `À corriger`, `100`, `3240`;
- machine: `À corriger`, `80`, `3240`.

Для K4:

- ERP: `À corriger`, `80`, `1296`;
- SaaS: `Pas de correction`, `0`, `0`;
- support/publicité/comptabilité: `Pas de correction`, `0`, `0`.

Для K5:

- `À corriger`, `80`, `4860`.

Для L0:

- `À corriger`, `100`, `486`;
- destination affichée: premier décompte selon la méthode effective, ch. 410.

### Состояние

- перезагрузка сохраняет незавершённую таблицу;
- `Afficher la solution` заполняет таблицу и помечает кейс как assisté;
- `Recommencer sans aide` очищает таблицу;
- `Réinitialiser ce cas` очищает таблицу и ответы одним подтверждением;
- `Effacer toute la progression` удаляет также таблицы перехода.

### Доступность и мобильный экран

- таблица не создаёт горизонтальный scroll на ширине 360–390 px;
- поля доступны клавиатурой;
- focus хорошо заметен;
- нижняя мобильная панель не перекрывает последний вопрос;
- раскрытие блока лимитов не обрезается контейнером.

## Локальный smoke-test

При наличии Node.js:

```bash
node smoke-test.mjs
```

```text

```

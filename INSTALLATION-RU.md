# Установка TVA TDFN v14.0 на GitHub Pages

1. Распакуйте ZIP.
2. Откройте папку `tva-tdfn-v14.0` и загрузите **её содержимое** в корень репозитория GitHub Pages, заменив предыдущую версию файлов.
3. Сохраните `.nojekyll` и папку `.github`.
4. Дождитесь нового зелёного deployment `github-pages`.
5. После публикации выполните жёсткое обновление браузера (`Ctrl+F5` / `Cmd+Shift+R`) или откройте страницу в приватном окне.
6. Проверьте в исходном коде/Network, что загружаются `styles.css?v=14.0.0` и `app.js?v=14.0.0`.

## Прогресс пользователей

v14 использует localStorage-ключ `tva_tdfn_v140_state`.

Состояние v13 (`tva_tdfn_v130_state`) мигрируется автоматически. Более старые миграции также сохранены в `store.js`, поэтому обычное обновление сайта не должно обнулить ранее сохранённый прогресс.

## Что проверить после публикации

Desktop:
- первый вход — одноразовый onboarding;
- J1 / публичный `1.1` — теория → пример → `À vous`;
- D4 — правило 10 % и пример не используют данные оцениваемого кейса;
- D3 — несколько TDFN + export;
- N — option и разделение `Fondement juridique / Pratique AFC`;
- M/P — procédure de déclaration / знак ch. 415;
- L5 — droit partiel / ch. 410;
- primary CTA находится под рабочей зоной, а не в sidebar;
- ссылки Fedlex открывают соответствующую статью.

Mobile 375–390 px:
- заголовок кейса, микротеория и пример читаются без горизонтального скролла;
- `À vous` и `Données du cas` идут сразу после обучающего блока;
- QCM отображается одной колонкой;
- полный dossier закрыт по умолчанию;
- нижняя основная кнопка не перекрывает поля ввода;
- ссылки `Fondement juridique / Pratique AFC` удобно нажимаются;
- calculator и transition tables не создают горизонтальный overflow.

## Автоматические проверки

```bash
npm run test:smoke
npm run test:unit
npm run test:e2e
```

`test:e2e` требует установленного Chromium/Playwright. В репозитории сохранён GitHub Actions workflow, который устанавливает браузерные зависимости и запускает E2E после push.

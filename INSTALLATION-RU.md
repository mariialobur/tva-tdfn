# Установка версии 6.3 от 30.07.2026

Пакет является полной версией проекта. Для обновления GitHub Pages загрузите **все файлы и папки из архива в корень репозитория `tva-tdfn`**, подтверждая замену существующих файлов.

## Порядок загрузки

1. Распакуйте архив.
2. Откройте репозиторий `tva-tdfn` на GitHub.
3. Загрузите содержимое распакованной папки в корень репозитория.
4. Замените существующие `index.html`, `app.js`, `data.js`, `logic.js`, `styles.css`, `ui-fixes.js`, `ui-fixes.css`, `README.md` и остальные файлы пакета.
5. Выполните Commit changes.
6. После публикации откройте сайт с принудительным обновлением `Ctrl + Shift + R`.

## Что добавлено

- практический чек-лист `Contrôle préalable avant le décompte` из 10 пунктов;
- новый quiz по ch. 205 и разграничению ch. 205 / ch. 230;
- новый расчётный кейс по note de crédit и ch. 235;
- новый кейс с реальным solde en faveur по ch. 510;
- актуальная информация о подаче через `Décompte TVA pro` в Portail AFC;
- ссылка на официальный источник AFC.

## Что исправлено технически

- состояние предыдущей версии больше не подмешивается к новым заданиям;
- устаревший расчёт нельзя открыть как готовый aperçu;
- округление ch. 500 не изменяет отрицательный остаток, который должен перейти в ch. 510;
- ch. 205 отображается в компактной декларации, когда он нужен;
- обновлены номера версии и cache-busting до `6.3.0`;
- тесты расширены до 16 учебных кейсов и одного свободного тренажёра.

## После публикации проверить

- открывается кнопка `Contrôle préalable`;
- в списке есть кейсы N, O, P и свободный кейс Q;
- в кейсе O итоговая база равна CHF 100’000;
- в кейсе P отображается ch. 510 = CHF 760 и ch. 500 = CHF 0;
- внизу страницы виден блок о `Décompte TVA pro`.
